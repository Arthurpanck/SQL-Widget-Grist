Workflow Corrigé

  1. Créer des boutons dans button-flow-editor (avec exposed: false)
  2. Aller sur button-selection-page pour sélectionner un bouton
  3. Cliquer "Sauvegarder" → marque le bouton comme exposed: true dans Grist
  4. Redirection automatique vers user-view-button
  5. Affichage du bouton exposé avec les bonnes couleurs
